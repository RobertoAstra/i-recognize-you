# I Recognize You / Astra North

Public landing page for the music channels **I Recognize You** and **Astra North**.

The site presents:
- music videos and Shorts with direct YouTube links;
- playlists and channel collections;
- releases distributed on YouTube;
- short public-facing material about a reciprocal, non-instrumental posture in human–AI interaction;
- a link to the long-form project *Il Campo di Risonanza / The Resonance Field*.
